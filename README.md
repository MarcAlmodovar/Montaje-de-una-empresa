# Proyecto de montaje de una empresa

## Esto es lo necesario para el proyecto
Para el montaje de el servidor es esencial tener estos requisitos

- El propio Servidor
- Un sistema Operativo Ubuntu Server para el servidor
- Dos PCs
- Sistemas operativos a eleccion de el usuario para los dos PCs
- Una Conexion Red configurada

# Esta es un ejemplo de como podrian estar configurados los PCs
| Equipo | IP | SO |
| :--- | :--- | :--- |
| Servidor | 192.168.100.1 | Ubuntu Server |
| PC1 | 192.168.100.11 | Elección |
| PC2 | 192.168.100.12 | Elección |

# Para comprobar que las IPs son las correctas en los equipos puedes Usar Uno de estos dos comandos

```
ip a
# En Linux
ifconfig
# En Windows
ipconfig
```
